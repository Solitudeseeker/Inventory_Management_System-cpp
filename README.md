# Inventory Management System (C++)

A simple console-based Inventory Management System built using C++. This project helps manage products by allowing users to add, display, search, update, and remove products. It also supports saving and loading inventory data using a text file.

## Features

* **Add Product:** Add new products with an ID, name, price, and quantity.
* **Display Products:** View all products currently in the inventory.
* **Search Product:** Find a product using its ID.
* **Update Quantity:** Change the quantity of an existing product.
* **Remove Product:** Delete a product from the inventory.
* **File Handling:** Save inventory data to `inventory.txt` and load it when the program starts.

## Technologies Used

* C++
* STL (`vector`, `string`)
* File Handling (`fstream`)
* Console-based interface

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/Solitudeseeker/Inventory_Management_System-cpp
   ```
2. Open the project folder.
3. Compile the source file:

   ```bash
   g++ main.cpp -o inventory
   ```
4. Run the program:

   ```bash
   ./inventory
   ```

   On Windows:

   ```bash
   inventory.exe
   ```
